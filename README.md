# Daylight and Moon Phases

A small three.js demonstrator showing how the length of the day changes as the tilted Earth orbits the Sun, and how the Moon's phases look from Earth.

- **Orbit view**: the Earth's yearly orbit with solstices and equinoxes.
- **Earth view**: day/night boundary and daylight at a chosen latitude.
- **Moon from Earth view**: the Moon's current phase, with a top-down inset.

Single static page (`index.html`), no build step. three.js is loaded from cdnjs.
